* Numpy Pandas y Matplotlib

/Numpy/ es la librearía de Python para cálculo científico matricial. Se
pueden declarar matrices de cualquier tamaño y realizar operaciones
matemáticas sobre ellas. Los objetos de /Numpy/ son esencialmente
numéricos. En /pandas/, en cambio, se puede trabajar tipos de datos
distintos pudiendo de esta manera enlazar con bases de datos.

/Matplotlib/ es la librería de Python para la creación de
gráficos numéricos como: barras, pasteles, tipo caja, entre
otros. También permite presentar imágenes.

** Ejercicio

Un perceptron es el modelo más simple para una red neuronal artificial. Consta
de una sóla neurona. La neurona se conecta directamente a un vector de
características $\mathbf{x} \in \mathbb{R}^N$ i.e.
$\mathbf{x}=(x_1,x_2, \cdots, x_N)$. La salida se computa aplicando una función
de activación a la suma ponderada de las entradas $\mathbf{x}$ por pesos
asociados a cada entrada más un valor de sesgo $b$. Es decir:

$$
z = f\left(\sum w_i\cdot x_i+b\right)
$$

Considere $N=5$. Declare un vector de valores aleatorios enteros entre $0$ y
$10$ de tamaño $5$ para $\mathbf{x}$ y una matriz de pesos aleatorios reales con
rango $[0,1]$. Para la función de activación considere una sigmoide
$\theta(x)=\frac{1}{1+e^{-x}}$. Proponga una solución que use el producto
matricial. Para $b$ tome un valor aleatorio real entre $0$ y $1$.

- Para $\mathbf{x}$ plantee un vector columna ~(5,1)~.
- Para $w$ plantee un vector de forma ~(1,5)~.
- Aplique la multiplicación matricial ~np.matmul(w,x)+b~.
- Aplique la función sigmoide al valor obtenido en el paso anterior.

$$
z = \theta \left ( W^{1\times 5} \times X^{5\times 1}\right)
$$

#+begin_src jupyter-python :session t :exports both
# x = np.random.randint(??, size=(??))
# w = np.random.random((??))
# b = np.random.random(??)
print(f"x:{x}\nshape:{x.shape}")
print(f"w:{w}\nshape:{w.shape}")
z0 = np.matmul(w,x)  # Producto punto
z = 1/(1+np.exp(-(z0)))  # Función de activación sigmoide
print(f"z:{z}\nshape:{z.shape}")
#+end_src

** Tabla cruzada
